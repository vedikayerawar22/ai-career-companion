
# AI Career Companion

A project to make the job search more organized for students and fresh graduates in technology.

## Planned Features

- Track companies, roles, and application status
- Store job descriptions and application links
- Track follow-ups and referral messages
- Prepare interview questions and answers
- Record daily learning and DSA practice
- Explore AI-powered resume and interview assistance

## Planned Tech Stack

- Flutter and Dart
- Firebase Authentication and Firestore
- AI integration (planned)

## Project Status

Planning and initial setup.
